Formatos Soportados & Ayuda

MarkItDown Studio utiliza el motor oficial de Microsoft para convertir una amplia gama de formatos a Markdown estándar de forma fiel y rápida:

PDF (.pdf)

Extrae texto, tablas estructuradas y jerarquía de títulos.

Word (.docx, .doc)

Convierte encabezados, listas, negritas, cursivas y tablas.

Excel (.xlsx, .xls)

Convierte hojas de cálculo completas a tablas Markdown limpias.

PowerPoint (.pptx)

Extrae diapositivas en títulos y viñetas Markdown.

CSV & Datos (.csv, .json, .xml)

Estructura los datos tabulares o formateados.

Web & Texto (.html, .htm, .txt)

Limpia etiquetas HTML complejas y preserva el contenido.

Guardado en Ruta Local
